# Window Block Export (WinPlax Prototype v0.1)

Минимальный Python-скелет для формирования геометрической модели окна и экспорта параметрического блока в форматы DXF/DWG без использования AutoCAD.

---

## 1. Назначение и возможности

Прототип проверяет принципиальную возможность формирования блока окна средствами Python и библиотеки `ezdxf`:
- Чтение параметров окна из `params.json`.
- Полная валидация входных данных (габариты, швы, размеры профилей, сетка, типы створок).
- Расчёт геометрической модели: рама (наружный и внутренний контуры), вертикальные и горизонтальные импосты, сетка ячеек, наплавы створок, подставочный профиль.
- Строгая проверка замыкания сетки (погрешность < $10^{-6}$ мм).
- Создание DXF-документа версии **R2013** (AC1027), совместимого с AutoCAD 2013–2026+.
- Формирование именованного блока `WW_<window_name>_<cols>x<rows>_001` (например, `WW_ОК-1_3x2_001`).
- Генерация 8 атрибутов блока (`ATTDEF` в блоке + `ATTRIB` во вхождении блока): `OBJECT`, `WINDOW_NAME`, `COLOR_OUT`, `COLOR_IN`, `GLAZING`, `SIZE_W`, `SIZE_H`, `GRID`.
- Вставка блока в ModelSpace в точке `(0, 0)` в масштабе 1:1.
- Размещение всех элементов на слое `Окна`.
- Опциональная конвертация DXF → DWG через ODA File Converter (при наличии).

---

## 2. Системные требования

- **Python**: 3.10 или новее (проверено на Python 3.11).
- **Библиотеки**: `ezdxf` (>= 1.0).
- **AutoCAD**: 2016, 2023 или любой другой DWG/DXF-совместимый CAD-редактор.
- **ODA File Converter** (опционально): для автоматической конвертации в `.dwg`.

## 3. Установка

1. Установите зависимость `ezdxf`:

## 5. Быстрый запуск

Запуск экспорта с параметрами по умолчанию (`params.json`):

```bash
python window_export.py
```

Или с явным указанием пути к конфигурационному файлу и целевому файлу:

```bash
python window_export.py path/to/custom_params.json --output output/CustomWindow.dxf
```

## 6. Формат конфигурации (params.json)

```json
{
  "version": "0.1",
  "window_name": "ОК-1",
  "opening": { "width": 1500, "height": 1500, "seam": 30 },
  "frame":   { "face_width": 60, "face_height": 60 },
  "mullion": { "width": 80, "height": 80 },
  "sash":    { "overlap": 15 },
  "sill":    { "on": true, "height": 30 },
  "addons":  { "left": 0, "right": 0, "top": 0 },
  "cols": 3,
  "rows": 2,
  "separators": {
    "vertical": [
      { "index": 1, "kind": "MULLION" },
      { "index": 2, "kind": "MULLION" }
    ],
    "horizontal": [
      { "index": 1, "kind": "MULLION" }
    ]
  },
  "cells": [
    { "row": 1, "col": 1, "sash_type": "TURN" },
    { "row": 1, "col": 2, "sash_type": "TURN_TILT" },
    { "row": 1, "col": 3, "sash_type": "FIX" },
    { "row": 2, "col": 1, "sash_type": "TILT" },
    { "row": 2, "col": 2, "sash_type": "FIX" },
    { "row": 2, "col": 3, "sash_type": "FIX" }
  ],
  "metadata": {
    "object": "Тестовый объект",
    "window_name": "ОК-1",
    "color_out": "RAL 8017",
    "color_in": "RAL 9016",
    "glazing": 32
  },
  "view": "OUTSIDE"
}
```

### Параметры:
- `opening`: габариты проёма (`width`, `height`) и монтажный шов (`seam`).
- `frame`: видимая ширина профиля коробки (`face_width`, `face_height`).
- `mullion`: ширина профиля импоста (`width`, `height`).
- `sash.overlap`: нахлёст (наплав) створки на раму/импост (мм).
- `sill`: подставочный профиль (`on`: включён, `height`: высота профиля, мм).
- `cols`, `rows`: размерность сетки окна (колонки и строки).
- `cells`: типы заполнения ячеек:
  - `FIX` — глухое остекление (без накладного контура створки);
  - `TURN` — поворотная створка (прямоугольный контур створки);
  - `TILT` — откидная створка (контур + диагональ индикации);
  - `TURN_TILT` — поворотно-откидная створка (контур + средняя линия и две диагонали).
- `metadata`: объект, маркировка, цвета по RAL, толщина стеклопакета.

## 7. Инструкция по проверке файла в AutoCAD

1. Запустите AutoCAD (версии 2016, 2023 или новее).
2. Откройте файл `output/ОК-1.dxf` через меню **Файл → Открыть** (выбрав тип файлов `.dxf`).
3. Введите в командной строке команду `_ZOOM` затем `_E` (Показать всё / Zoom Extents).
4. **Проверка блока**:
   - Кликните по окну. В палитре **Свойства** (`_PROPERTIES`, Ctrl+1) отображается:
     - Тип объекта: `Вхождение блока` (`Block Reference`).
     - Имя блока: `WW_ОК-1_3x2_001`.
     - Положение: `X=0, Y=0, Z=0`.
     - Масштаб: `1, 1, 1`.
     - Слой: `Окна`.
5. **Проверка атрибутов**:
   - Дважды кликните по блоку левой кнопкой мыши (или вызовите команду `_EATTEDIT`).
   - Откроется диалоговое окно «Расширенный редактор атрибутов».
   - Должны присутствовать 8 атрибутов:
     - `OBJECT` = `Тестовый объект`
     - `WINDOW_NAME` = `ОК-1`
     - `COLOR_OUT` = `RAL 8017`
     - `COLOR_IN` = `RAL 9016`
     - `GLAZING` = `32`
     - `SIZE_W` = `1500`
     - `SIZE_H` = `1500`
     - `GRID` = `3×2`
6. **Проверка геометрии и разбиения**:
   - Выделите блок и вызовите команду `_EXPLODE` (Расчленить).
   - Блок распадается на составляющие примитивы: полилинии рамы, импостов, подставочного профиля и отрезки створок.
   - Все примитивы остаются на слое `Окна`.

## 8. Конвертация в DWG (ODA File Converter)

Скрипт автоматически ищет установленный [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) по стандартным путям:
- Windows: `C:\Program Files\ODA\ODAFileConverter*\ODAFileConverter.exe`
- Linux/macOS: утилита `ODAFileConverter` в `PATH`.

Если конвертер установлен, скрипт автоматически создаёт файл `output/ОК-1.dwg` версии AutoCAD 2018. При отсутствии конвертера вывод продолжается в формате DXF R2013 без ошибок.

## 9. Запуск автоматических тестов

Для запуска полного набора тестов (проверка всех 14 сценариев ТЗ v0.1):

```bash
python test_window_export.py -v
```

Тесты проверяют:
- Корректность создания и валидность структуры DXF R2013;
- Отсутствие ошибок при аудите документа (`auditor.errors == []`);
- Математическую точность замыкания сетки;
- Принадлежность всех примитивов и атрибутов слою `Окна`;
- Корректность заполнения всех 8 атрибутов;
- Поведение при нестандартных сетках (1×1, 8×4);
- Реакцию на некорректные входные параметры (блокировка создания файла).
