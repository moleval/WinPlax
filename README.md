# Window Block Export (WinPlax v0.2)

Параметрический генератор оконного блока и экспорт в DXF/DWG без использования AutoCAD, в строгом соответствии с ГОСТ 21.501, ГОСТ 23166 (ТЗ 0.2).

---

## 1. Назначение и возможности

Модуль формирует параметрическую чертёжную модель оконного блока и экспортирует именованный блок в CAD-форматы (DXF R2013/DWG):

- Чтение параметров окна из `params.json` или аргументов CLI с полной валидацией.
- Расчёт геометрической модели:
  * **Габаритный контур проёма** `[(0,0) .. (OW,OH)]` — монтажный шов наглядно;
  * **Монтажные швы** и **коробка рамы** (наружный и внутренний контуры) с углами **под 45°**;
  * **Импосты** (вертикальные/горизонтальные);
  * **Створки** с **двухконтурным бруском 80 мм** (наружный наплав + внутренний световой проём) и **45° стыками** на 4 углах;
  * **Условные обозначения открывания** строго по **ГОСТ 21.501/23166** (треугольники к ручкам: боковая для `TURN`, верхняя для `TILT`, совмещение для `TURN_TILT`, `FIX` — без линий);
  * **Подставочный (донный) профиль**.
- Проверка замыкания сетки с погрешностью `<1e-6 мм`.
- Создание DXF-документа **R2013 (AC1027)** с кодировкой `ANSI_1251 / cp1251`.
- Формирование именованного блока `WW_<window_name>_<cols>x<rows>_001` (например, `WW_ОК-1_3x2_001`) и вставка в ModelSpace в `(0,0)` 1:1.
- Генерация **8 атрибутов** блока с кириллицей: высота **22 мм**, шаг **35 мм**, точка `(-200, OH)` (смещены левее, не наезжают на окно), стиль `WindowStyle` шрифт **`Arial.ttf`** (`GRID` — строго `3x2` латиница, без `?`).
- Размещение элементов: `Окна` (цвет 7) — рама, импосты, створки, подставочник; `Штриховые` (цвет 1, `DASHED`) — контур проёма.
- Подставочный профиль с зазором `S` (монтажный шов) между проёмом и подставочником.
- Отрисовка створки по `view`: `OUTSIDE` — наплав не виден (только внутренний контур), `INSIDE` — наплав виден и обрезает раму.
- Опциональная конвертация DXF → DWG через ODA File Converter (установка через `winget`).

## 2. Системные требования

- **Python**: 3.10 или новее (проверено на Python 3.11).
- **Библиотеки**: `ezdxf` (>= 1.0).
- **AutoCAD**: 2016, 2023 или любой DWG/DXF-совместимый CAD-редактор.
- **ODA File Converter** (опционально): для автоматической конвертации в `.dwg`.

## 3. Установка

### 3.1 Windows — PowerShell (ваш случай)

Если видите ошибку `ModuleNotFoundError: No module named 'ezdxf'`:

```powershell
# 1. Проверьте версию Python (должно показать 3.10+)
python --version
py --version

# 2. Установите библиотеку ezdxf (любая из команд — выберите ту, где python найден):
python -m pip install ezdxf
# или
py -m pip install ezdxf
# или без прав администратора:
python -m pip install --user ezdxf
# или из файла зависимостей (в папке проекта):
python -m pip install -r requirements.txt

# 3. Проверьте установку:
python -m pip show ezdxf
python -c "import ezdxf; print(ezdxf.__version__)"
```

Если видите ошибку `Имя "generate_examples.py" не распознано` — **в PowerShell нельзя запускать `.py` напрямую**. Обязательно добавляйте `python`:

```powershell
# ❌ Неправильно:
# generate_examples.py
# window_export.py

# ✅ Правильно:
python window_export.py
python generate_examples.py
# или, если 'python' не найден:
py window_export.py
py generate_examples.py

# Также работает:
python -m pip --version
```

> Подсказка Windows: ошибка `Suggestion [3,General]: ... введите ".\generate_examples.py"` не поможет — всё равно нужен `python` впереди.

### 3.2 macOS / Linux

```bash
pip install ezdxf
# или

# В изолированных окружениях Debian/Ubuntu при необходимости добавьте --break-system-packages или используйте venv:
```

Запуск экспорта с параметрами по умолчанию (`params.json`):

```powershell
python window_export.py
```

## 6. Формат конфигурации (params.json) — ТЗ 0.2

```json
{
  "version": "0.2",
  "window_name": "ОК-1",
  "opening": { "width": 1500, "height": 1500, "seam": 30 },
  "frame":   { "face_width": 60, "face_height": 60 },
  "mullion": { "width": 80, "height": 80 },
  "sash":    { "overlap": 15, "profile_width": 80 },
  "sill":    { "on": true, "height": 30 },
  "addons":  { "left": 0, "right": 0, "top": 0 },
  "cols": 3,
  "rows": 2,
  "separators": {
    "vertical": [
      { "index": 1, "kind": "MULLION" },
      { "index": 2, "kind": "MULLION" }
    ],
    "horizontal": [
      { "index": 1, "kind": "MULLION" }
    ]
  },
  "cells": [
    { "row": 1, "col": 1, "sash_type": "TURN" },
    { "row": 1, "col": 2, "sash_type": "TURN_TILT" },
    { "row": 1, "col": 3, "sash_type": "FIX" },
    { "row": 2, "col": 1, "sash_type": "TILT" },
    { "row": 2, "col": 2, "sash_type": "FIX" },
    { "row": 2, "col": 3, "sash_type": "FIX" }
  ],
  "metadata": {
    "object": "Тестовый объект",
    "window_name": "ОК-1",
    "color_out": "RAL 8017",
    "color_in": "RAL 9016",
    "glazing": 32
  },
  "view": "OUTSIDE"
}
```

### Параметры:
- `opening`: габариты проёма (`width`, `height`) и монтажный шов (`seam`).
- `frame`: видимая ширина профиля коробки (`face_width`, `face_height`).
- `mullion`: ширина профиля импоста (`width`, `height`).
- `sash.overlap`: нахлёст (наплав) створки на раму/импост (мм).
- `sash.profile_width`: ширина бруска створки (мм, по умолчанию 80) — формирует внутренний световой проём.
- `sill`: подставочный профиль (`on`: включён, `height`: высота, мм) — с зазором `S`: `[(S,-S-SH),(OW-S,-S-SH),(OW-S,-S),(S,-S)]` (зазор между проёмом `y=0` и верхом подставочника `y=-S` равен монтажному шву `S`).
- `cols`, `rows`: размерность сетки.
- `cells`: типы заполнения ячеек:
  - `FIX` — глухое (без створки);
  - `TURN` — поворотная (треугольник к боковой ручке: 2 линии по ГОСТ);
  - `TILT` — откидная (треугольник к верхней ручке: 2 линии);
  - `TURN_TILT` — поворотно-откидная (совмещение: 4 линии).
- `metadata`: объект, маркировка, цвета RAL, толщина стеклопакета.
- `view`: `OUTSIDE` (вид с улицы, наплав не виден) / `INSIDE` (вид изнутри, наплав обрезает раму).

**Геометрические формулы (ТЗ 0.2 п.3.3):**
- `FRAME_OUTER = [(S,S)…]`, `FRAME_INNER = [(S+FW,S+FH)…]`, стыки 45° по диагоналям углов.
- `GRID_W = (OW-S-FW)-(S+FW)`, `CELL_W = (GRID_W-ΣV)/COLS`, замыкание `|COLS·CELL_W+ΣV-GRID_W|<1e-6`.
- Створка наружная `[(x1-SO,y1-SO)…]`, внутренняя `[(x1-SO+SW …)]`, 4 стыка 45°.
- ГОСТ-стрелки по световому проёму `[in_x1,in_x2]×[in_y1,in_y2]`.

## 7. Спецификация атрибутов блока (8 шт.)

| Тег | Подсказка | Пример | Назначение |
|---|---|---|---|
| `OBJECT` | Объект | `Тестовый объект` | Наименование объекта |
| `WINDOW_NAME` | Название окна | `ОК-1` | Марка |
| `COLOR_OUT` | Цвет снаружи | `RAL 8017` | Ламинация снаружи |
| `COLOR_IN` | Цвет изнутри | `RAL 9016` | Внутри |
| `GLAZING` | Толщина заполнения | `32` | Стеклопакет мм |
| `SIZE_W` | Ширина проёма | `1500` | мм |
| `SIZE_H` | Высота проёма | `1500` | мм |
| `GRID` | Сетка | `3x2` | Формула разбивки (латиница `x`) |

*Оформление:* стиль `WindowStyle` (`Arial.ttf`), высота **22 мм**, первая точка `(-200, OH)` (левее, не наезжает на окно), шаг **35 мм** вниз, слой `Окна`.

## 8. Требования к DXF-документу

- Версия **R2013 (AC1027)**, `$DWGCODEPAGE = ANSI_1251`, `encoding = cp1251`.
- Имя блока `WW_<window_name>_<cols>x<rows>_001` (латиница `x`).
- Точка вставки `(0,0,0)`, масштаб `1:1:1`, поворот `0°`.
- Слои: `Окна` (цвет 7, `Continuous`) — основная геометрия; `Штриховые` (цвет 1, `DASHED`) — контур проёма.
- Подставочник: зазор `S` к проёму; атрибуты `(-200, OH)` `22мм` `35мм`.

---

## 9. Инструкция по проверке файла в AutoCAD

1. Откройте `output/ОК-1.dxf` в AutoCAD 2016+ (`_ZOOM _E`).
2. Проверка блока: `_PROPERTIES` показывает `WW_ОК-1_3x2_001`, `(0,0,0)`, `1:1:1`, слой `Окна`.
3. Проверка атрибутов (`_EATTEDIT`): 8 атрибутов, высота **22**, шрифт **Arial**, `GRID=3x2` (без `?`), точка `(-200,1500)` шаг 35, не наезжают на окно.
4. Проверка слоёв: `_LAYER` — `Окна` (7) и `Штриховые` (1, `DASHED` для проёма `1500×1500`).
5. Проверка геометрии: `_EXPLODE` — рама 45°, импосты, створки (для `OUTSIDE` наплав скрыт, для `INSIDE` виден), ГОСТ-треугольники, подставочник с зазором `S=30` ниже проёма.

## 10. Конвертация в DWG (ODA File Converter)

**Установка через winget (Windows 10/11):**
```powershell
winget search "ODA File Converter"
winget install --id ODA.ODAFileConverter -e --accept-package-agreements
# альтернативные id: ODA.ODAFileConverter, OpenDesign.ODAFileConverter
# проверьте: where ODAFileConverter
# или вручную: https://www.opendesign.com/guestfiles/oda_file_converter
```
Скрипт ищет `ODAFileConverter.exe` в `C:\Program Files\ODA\` и в `PATH`. При наличии создаёт `output/ОК-1.dwg` (ACAD2018), иначе пропускает с сообщением `ODA File Converter не найден`.

## 11. Запуск автоматических тестов

Для запуска полного набора тестов (15 сценариев ТЗ v0.2):

```bash
python test_window_export.py -v
```

Тесты проверяют:
- Версию DXF R2013 и кодировку `ANSI_1251`/`cp1251`;
- Аудит (`auditor.errors == []`);
- Замыкание сетки `1e-6`;
- Слои `Окна` (7) и `Штриховые` (`DASHED` для проёма) — проём на `Штриховые`, остальное на `Окна`;
- 8 атрибутов (`3x2` латиница, высота **22**, `WindowStyle`/`Arial.ttf`, координаты `-200,OH` шаг **35**, не наезжают);
- Точку вставки и масштаб;
- Имя блока `WW_ОК-1_3x2_001`;
- ODA-обработку;
- Пересчёт при изменении габаритов;
- Сетки `1×1` и `8×4`;
- Отклонение некорректных параметров;
- Геометрию v0.2+: проём `1500×1500` штриховой, рама 45°, створки двухконтурные 80мм+45° (OUTSIDE наплав скрыт / INSIDE виден), ГОСТ-стрелки, подставочник с зазором `S`.
